# agent-dealer 0.1.2

Patch release — configurable per-phase budgets; real runs use Claude runtime defaults unless you set caps.

## Install / upgrade

```bash
npm install -g agent-dealer@0.1.2
agent-dealer setup
agent-dealer start --open
```

Dashboard + API: **http://localhost:2222** (bundled UI on one port).

## Highlights

### Budget & limits

- **Default (production)** — no `--max-turns` or `--max-budget-usd` on the CLI when budgets are unset; Claude uses its own limits
- **Agent defaults** — optional plan/execution max turns and USD per saved agent
- **Per-run overrides** — set plan budget on replan; set execution budget on approve or kick
- **Separate phases** — plan, execute, and reflect each resolve their own caps

### UI

- **PhaseConfigRow** — Plan and Execution clusters: Model · Turns · Max USD in one row (Agents page + review drawers)

### Testing

- `flow:verify` injects explicit test caps (`plan 5/$0.50`, `execute 30/$5`)
- Legacy run `budget_json` `{ maxTurns, maxBudgetUsd }` treated as execute-only override

## Verification

- `npm run build:release` · `npm run install:smoke` · `npm run flow:verify` (API gates)
