# agent-dealer 0.1.1

Patch release — fixes production config loading for `npm install -g agent-dealer` users.

## Install / upgrade

```bash
npm install -g agent-dealer@0.1.1
agent-dealer setup          # or setup --force to refresh template (back up keys first)
agent-dealer doctor         # config path, LINEAR_API_KEY, port 2222
agent-dealer start --open
```

Dashboard + API: **http://localhost:2222** (bundled UI on one port).

## Fixes

- **Load `~/.agent-dealer/.env` in CLI** — `start` and `doctor` read the file before resolving port or spawning the server (Linear keys, etc. are in effect without shell exports).
- **Bundled port 2222** — legacy `PORT=2221` in old templates is ignored when the dashboard bundle is present; start logs `Config: ~/.agent-dealer/.env`.
- **Doctor** — reports `LINEAR_API_KEY set`, data directory, and effective bundled port.
- **Setup template** — default `PORT=2222` and aligned API/web URLs for single-port npm install.

## Verification

- `npm run install:smoke` — env-file load, legacy PORT=2221 → 2222, health + dashboard + `/api/snapshot`
