# agent-dealer 0.1.0

First daily-driver release — git tag `v0.1.0` and installable npm package `agent-dealer@0.1.0`.

## Install

```bash
npm install -g agent-dealer
agent-dealer setup
agent-dealer doctor    # Node, Claude CLI, bundle, port
agent-dealer start --open
```

Dashboard + API: **http://localhost:2221** (bundled UI on one port).

From git: `git checkout v0.1.0` → `npm ci` → `npm run dev` (dev ports 3221/3222).

## Highlights

### Operations & review

- Four-column Operations layout (In Planning / In Progress strips + Review Plan / Review Result)
- Markdown preview for plans, deliverables, and approved plan in review drawer
- Lineage **usage rollup** (plan, execute, retry, total) and **chronological reasoning trace**
- Execution **retry** reuses approved plan (not replan); Linear → In Progress; `--resume` + prior context

### Integrations

- Linear write-back at plan / review / retry / done milestones
- Post-review playbook reflect + propose-confirm patch (Agent Deck)

### npm packaging

- Real CLI (`setup`, `start`, `doctor`) with bundled server + dashboard
- `doctor` checks Claude Code on PATH (common install locations)
- Publish via staged tarball — monorepo root stays `private` (do not `npm publish` from repo root)

### Trust & execution

- Plan: Read/Glob/Grep + Agent Deck MCP — budget-capped (`--max-turns`, `--max-budget-usd`)
- Execute: Read/Write/Edit/Glob/Grep/Bash in task workspace — human approves plan and result
- See README **Trust & execution scope**

## Verification

- `npm run build:release` · `npm run install:smoke` — fresh npm pack install test
- `npm run flow:verify` — API lifecycle gates (`scripts/flow-verify.ts`)
