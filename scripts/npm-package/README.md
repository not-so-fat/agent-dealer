# agent-dealer

Human control plane for agent execution — queue, plan approval, agent runs, and audit.

**This npm package is a versioned pointer.** The app is developed and installed from the GitHub repo (monorepo, not an npm installable CLI yet).

## Install (v0.1.0)

```bash
git clone https://github.com/not-so-fat/agent-dealer.git
cd agent-dealer
git checkout v0.1.0
npm ci && npm run build
```

Quick start: see [README](https://github.com/not-so-fat/agent-dealer/blob/v0.1.0/README.md) and [PROD_SETUP](https://github.com/not-so-fat/agent-dealer/blob/v0.1.0/docs/PROD_SETUP.md).
